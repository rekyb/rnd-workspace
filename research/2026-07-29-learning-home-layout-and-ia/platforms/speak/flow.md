# Flow — Speak home (iOS)

**Summary:** `Home` is a unit path rendered as staggered cards rather than a single column;
`Profile` carries the course list and a reverse-chronological activity log. Five labelled tabs.

Layout study. System-response claims **inferred from screen sequence**.

**1. Arrival — `Home`, with two controls above the content.**
A `Level ▾` chip on the left, a `Course` / `Practice` segmented control in the centre with
`Course` active, and a streak chip (`0`) on the right. Below, a thin rule and a unit label:
`UNIT 1` over the unit name (`New Destinations`).
*Evidence: reference 02.*

**2. The path is a staggered sequence of cards, not a column of nodes.**
Five items descend the screen, each a rounded card with a small character avatar and a label —
`Welcome!` (filled blue, the current step), then `Ask for information`, `Book accomodation`,
`Ask for directions`, and `Check your progress` (carrying a numbered badge). Cards alternate
their horizontal offset rather than sitting in one column, and a floating character sits at the
lower right. One card (`Aa`) sits off to the side as a separate affordance.
*Evidence: reference 02.*

**3. The bottom bar carries five destinations, each labelled.**
`Home`, `Free Talk`, `Review`, `Challenge`, `Profile` — icon above a text label, active tab
tinted. **No overflow control.**
*Evidence: reference 01, 02.*

**4. `Profile` opens with the course list, not with identity.**
A settings gear sits alone in the header. The first block is `Your Courses` with a
`View All Courses` link, then course rows: a thumbnail, a title (`Beginner Part 1`), a
sub-line naming the tutors (`With Alice, Louise and Noémie`), a `CURRENT` badge on the active
course, a completion percentage (`8% complete`), a thin progress bar, and a circular check
control on the right. A second row shows `Upper Elementary Part 1 · With Speak Tutor ·
0% complete`.
*Evidence: reference 01.*

**5. Then a reverse-chronological activity log, and the block ends with a link.**
`Your Activity Log` — rows each carrying an avatar, an activity name (`At a Crêperie`), a type
label (`Free Talk`), and a relative timestamp (`13m ago`, `1h ago`, `1h ago`). The block closes
with `See all activities`.
*Evidence: reference 01.*

---

**Not observed:** `Free Talk`, `Review`, and `Challenge` contents; the `Practice` segment of
`Home`; any web counterpart; timing and transitions.
